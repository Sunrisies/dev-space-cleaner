# 0.1.2：普通窗口与紧凑扫描界面

默认窗口从 1280×840 调整为 1080×680，居中显示，显式关闭 fullscreen 和 maximized；保留手动调整大小与最大化的能力。最小窗口为 960×600，适应屏幕缩放后仍能显示操作区域。

移除主区域的大标题、英文标语与装饰图，将页面标题放到顶栏。扫描控制缩小间距，范围说明与标题同行；三个统计卡片使用两行布局，保留大小、目录数、扫描耗时、读取错误等信息。

结果标题、语言筛选、搜索和排序合并为一行。虚拟列表行高从 80px 改为 64px，与实际行容器一致。页面外层保持不滚动，结果列表独立滚动，底部选择与清理按钮固定可见。

前端布局回归覆盖 1600×980、1280×810、1080×650、960×610、960×570 的内容区域，包含默认窗口减去标题栏后的尺寸与最小窗口。默认尺寸下列表可用高度超过 250px，其他尺寸也检查可用空间、底栏位置、列表滚动与 Escape 关闭设置弹窗。

界面截图：`docs/screenshots/desktop-compact.png`。扫描引擎、统计口径与清理流程本次没有修改；不重新声明或推算新的扫描性能。
