# 0.1.3：保存自定义扫描设置

在扫描设置中选择“自定义目录”、添加目录并点击“保存设置”。保存当前范围模式、自定义目录列表、扫描类型和线程数。下次启动读取已保存设置，用户点击“开始扫描”后执行；首次没有设置时仍默认全盘。

保存全盘模式时保留自定义目录列表。离线磁盘或暂时不存在的绝对路径可以保存，不因启动时不可访问而丢失；真正扫描时由引擎逐项校验。启动加载完成前禁用开始扫描，避免恢复自定义范围前误用默认全盘。

桌面通过 Tauri `app_config_dir` 定位用户配置目录，存储 `scan-settings.json`。写入使用同目录的独占新建临时文件、同步数据、关闭文件再重命名替换；同进程读写互斥，I/O 在后台阻塞线程执行。失败时保留旧文件并清除本次临时文件；损坏的文件在读取时只报错，不自动覆盖。设置结构包含版本号并在读写前验证。

普通浏览器预览使用独立 localStorage，便于页面回归；桌面版实际使用 Rust 配置文件。页面测试的重载结果不等同于 Mac 实机应用重启测试。

本轮验证：

- 4 项 Rust 设置文件测试通过：初次读取、中文绝对路径与离线目录往返、替换已有文件并保留自定义目录、非法配置拒绝覆盖、损坏内容保留、替换失败保留目标且清除临时文件。
- 3 项设置页面测试通过：恢复自定义范围与类型/线程数、修改并保存后重新打开恢复、全盘/自定义切换后目录仍在、损坏配置不自动覆盖、存储失败提示并保留旧值。
- 原有 5 个窗口尺寸布局测试通过。
- Clippy 无警告；前端 TypeScript 与生产构建通过。

界面截图：`docs/screenshots/settings-saved.png`。本次不保存扫描候选、勾选状态或清理权限；每次扫描仍生成新的候选会话。
