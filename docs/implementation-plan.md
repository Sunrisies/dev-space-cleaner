# 实施顺序

已根据用户批准的设计进入实现。当前技能目录中没有 writing-plans，直接将实施步骤记录在此。

1. 独立 Rust 引擎：磁盘枚举、受控并发、项目识别、逻辑大小统计、取消、错误摘要。
2. 核心验证：三语言混合目录、同名误判、链接、重叠根、多根失败隔离、取消与清理重校验。
3. Tauri：会话内候选注册、Channel、互斥状态、原生目录选择、回收站。
4. React：中文现代化页面、默认全盘、虚拟列表、筛选与详情、清理确认、明暗主题。
5. release 基准：生成可复现数据并测量，记录统计准确性、耗时和测量边界。
6. Windows 编译、前端构建和可行的页面检查；提供 macOS CI 与实机验收说明。

全程不对用户电脑上的真实依赖目录执行清理。
