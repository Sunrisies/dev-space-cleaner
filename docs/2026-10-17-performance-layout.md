# 0.1.1：D 盘扫描复核与固定页面布局

## 实际数据复核

用户提供的截图：D 盘扫描 64.94 秒，638 个候选目录，66.97 GiB，2 项读取错误。这个耗时不能直接与随后的热缓存运行比较。

在同一台 Windows 电脑上，按相同规则重新完整扫描 D 盘，记录如下。各轮均不读取文件内容，不清理目录，不清空操作系统文件缓存。

| 实现与线程数 | 耗时 | 目录结果 | 目标文件 | 逻辑字节总和 |
| --- | ---: | ---: | ---: | ---: |
| 0.1.0 引擎，4 线程 | 32.543 秒 | 638 | 2,628,141 | 71,929,082,046 |
| 优化引擎，4 线程 | 27.364 秒 | 638 | 2,628,141 | 71,929,082,046 |
| 优化引擎，8 线程 | 22.603 秒 | 638 | 2,628,141 | 71,929,082,046 |
| 优化引擎，16 线程 | 23.515 秒 | 638 | 2,628,141 | 71,929,082,046 |

逐一比较每条候选项的路径、类型、字节数、文件数、完整状态、错误数、跳过链接数，没有差异或遗漏。工作线程完成顺序不确定，ID 与事件到达顺序不用于比较。

在停止其他编译与独立复核任务后，最终代码又顺序复测了 8/16 线程：分别为 21.613 秒与 20.445 秒，两轮仍是同样的 638 个目录、2,628,141 个文件、71,929,082,046 字节，逐项无差异。加入明确的系统目录排除后，两项权限错误归零，检查的目录数为 564,901。

这些是顺序运行的开发机测量，不是冷缓存实验或具有统计置信度的基准；编译、杀毒软件、磁盘负载与系统缓存均可能影响结果。8/16 线程在不同轮次的先后顺序发生变化，不能声称其中一个总是最快。新版默认 8 线程以控制并发开销，用户可尝试 16；机械盘与网络盘可手动降低线程数。

## 独立算法抽查

使用 Node.js 标准库的独立程序逐路径调用 `lstat`，以 BigInt 累加逻辑大小，不调用 Rust 引擎或缓存结果。每种语言抽查一个最大、完整的候选目录：

| 类型 | 普通文件数 | 逻辑字节 | 跳过链接数 | 与扫描结果一致 |
| --- | ---: | ---: | ---: | --- |
| Node.js | 72,422 | 1,956,706,394 | 4,200 | 是 |
| Rust | 4,548 | 1,901,053,314 | 0 | 是 |
| Python | 39,313 | 5,135,440,717 | 0 | 是 |

三项抽查都没有读取错误。这验证了这些目录的统计，不代表对所有 638 个目录都做了独立复核。

原先两项错误为卷根目录 `Config.Msi` 与 `WindowsApps` 拒绝访问。它们是系统管理目录，新版把它们纳入默认系统目录排除规则。自定义项目内部的同名目录不会被排除；其他位置的权限不足仍然如实报告。界面在取消或存在读取错误时显示“部分统计”，不把不完整合计展示为完整结果。

大小口径保持为普通文件的逻辑字节总和，链接不跟随、硬链接按路径计数，不等于实际占用或清空回收站后的实际可释放空间。扫描期间文件变化也不具有快照一致性。

## 性能改动

- 目录枚举得到的元数据随任务传递，避免 Windows 上对每个发现的目录重复执行 symlink_metadata。
- 测量普通文件时不再逐文件构造完整路径，仅为子目录或错误构造路径。
- 文件数、字节数与链接数按批次更新共享计数；每 256 条检查一次进度，保留约 150ms 的界面推送节流。
- 每批结束、目录结束与取消退出前都合并剩余计数，避免遗漏尾批。
- 目录队列、识别规则、链接跳过和清理校验继续保留；不以少扫描用户项目来制造速度提升。

## 页面布局与检查

`html/body/root` 固定为窗口高度，主工作区不滚动。扫描控制与容量摘要固定，结果区占剩余高度，只有列表内容滚动。底部选择和清理栏始终可见。小高度窗口压缩固定控件，弹窗只滚动内部内容。

Playwright 使用系统 Chrome 实际检查 1600×980、1280×810、960×610 三个尺寸：页面没有外层滚动、列表高度可用、底栏位于窗口内、列表溢出时能够独立滚动、Escape 可以关闭设置弹窗。截图保存在 `docs/screenshots/desktop-fixed.png`。

新增批量计数测试：同一目录中的 769 个文件覆盖多个 256 条批次与最后尾批，并包含中文路径、零字节文件；1/4 线程结果一致。原有精确字节、多根、链接、取消、队列压力与清理校验测试继续执行。

本机最终检查：11 项默认 Rust 测试通过、1 项真实回收站测试保持显式选择执行；3 项页面尺寸测试通过；Clippy 无警告；Rust 格式检查通过；前端类型检查与生产构建通过。布局回归已加入 CI 配置，CI 与 Mac 实机本轮仍未在本地执行，不将其列为已验证。

## 复现

```sh
cargo run -p huanj-core --release --example scan_roots -- --workers 8 D:\
node scripts/audit-sizes.mjs <待核对目录>
node scripts/compare-scans.mjs <前一次JSONL> <后一次JSONL>
npm run test:ui
```

JSONL 日志可能含本机项目路径，原始 D 盘日志留在被忽略的本地测试目录，没有提交进 Git。
