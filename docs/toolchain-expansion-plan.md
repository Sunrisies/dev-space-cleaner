# 工具链扩展实施计划

已批准设计：superpowers/specs/2026-10-17-toolchain-expansion-design.md。
当前环境缺少 writing-plans 技能，使用本文件记录可执行计划。

1. 增加统一分类目录、独立识别模块；候选携带规则 ID，扫描与清理共用识别。
2. 实现项目级规则，按项目及生成标识识别，排除全局仓库、配置、SDK 和源码目录。CMake/Meson 仅纳入明确的内部生成目录，保留构建配置。
3. 兼容旧设置与类型 ID，拒绝未知类型；保持一次遍历与有界线程池。
4. 增加可搜索类型选择和内部滚动分类汇总，以真实目录名展示每条结果；保留整体布局高度。
5. 为每条规则验证识别、反例、字节数、嵌套去重与清理前标识变化；测试设置兼容、界面布局、类型筛选与菜单。
6. 运行构建、Rust 测试和 clippy、UI 测试，比较旧三类扫描基线与扩展后的扫描结果和耗时。
7. 构建安装包，记录验证边界及实际支持清单；有运行中的旧程序时不强制终止或覆盖安装。

状态：已完成。验证见 2026-10-17-toolchain-expansion.md；0.2.0 Windows 安装包已构建并升级，旧设置内容不变。全局缓存、非标准输出路径和 macOS 实机验证保持在文档明确列出的边界内。
